# Security Policy

## Reporting Security Issues

If you discover a security vulnerability in this project, please **do not** open a public issue. Instead, please email the maintainers directly with details of the vulnerability.

We take security seriously and will work to address any issues promptly.

## Security in Documentation

As this is primarily a documentation and decision repository, traditional security concerns are limited. However, we encourage all contributors to:

- Review decisions for architectural security implications
- Document security considerations in starter templates
- Share security best practices and lessons learned
